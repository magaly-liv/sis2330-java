# Semana 02: Fundamentos de Java

Tipos primitivos, operadores, control de flujo, arrays y metodos,
sin usar clases propias.

## Contenido

- `src/Fundamentos.java`: ejemplos de tipos, operadores, if/switch, bucles, arrays y metodos
- `src/SistemaCalificaciones.java`: capstone, notas de 5 estudiantes con Scanner

## Compilar y ejecutar

```bash
cd semana02
mkdir -p out
javac -d out src/Fundamentos.java src/SistemaCalificaciones.java
java -cp out Fundamentos
java -cp out SistemaCalificaciones
```
